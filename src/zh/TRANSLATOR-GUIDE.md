# 翻译规范（TRANSLATOR GUIDE）

适用范围：`src/zh/` 下全部译文文件。AI 初翻与人工校对共同遵守。
配合 `GLOSSARY.md` 使用。

## 总原则

1. **只译文字，不动结构**。所有 LaTeX 命令、环境、注释行、空行
   习惯尽量保持与原文文件一致，便于逐行对照与上游 diff。
2. **标识符永不翻译**：`\label{...}`、`\ref{...}`、`\index{...}`、
   `\hyperdef`/`\hyperref` 锚点、`\cite{...}` 键、文件名、宏名。
3. **数学原样**：`$...$`、`equation/align/gather` 等环境内的内容
   不翻译（其中的 `\text{...}`/`\hbox{...}` 内如为英文文字则翻译）。

## 具体规则

### 保留原样

- `\label`/`\index`/`\cite` 的参数
- 定义/定理/证明/练习等环境名（zhsetup.sty 已统一汉化）
- 原书编号引用，如 `One.I.1`、`Two.III.2.3`（正文提到时原样保留）
- `\grstep`、`\linsys`、`\amatrix` 等自宏的用法结构
- 参考书目 `bib/bib.tex`（第一阶段不译）
- `\index{...}` 条目（第一阶段保留英文；中文索引进遗留清单）

### 汉化要求

- 标点用全角：，。；：？！（）""''《》——……
  - 数学行内外的英文逗号句点仅在纯英文片段（如未经翻译的引用）
    中保留
- 数字、变量、单位与汉字之间照抄原文的 `~`（不可断空格），
  如 `$2$~千克`；原文没有 `~` 的一般也不添加
- 章首 `Chapter One` 由宏自动变成「第一章」，正文中如出现
  `Chapter One` 字样译为「第一章」，`Topic` 译为「专题」
- 星号小节说明（`\subsectionoptional` 的 `*`）不动
- `Figure N` 译为「图 N」；`the prior example` 译为「前面的例题」等
  指称按上下文自然化
- 语气：教材书面语；原文口语化的 motivation 段落保持亲切但不啰嗦

### 翻译三步自查

1. `make zh-book` 编译零 error；无 `Missing character` 警告
2. 打开该章 PDF 页面：阴影框、页眉、编号、超链接颜色正常
3. 术语与 `GLOSSARY.md` 一致；全角标点无混用

## 与上游同步

- 上游（Jim Hefferon GitLab）仅会修 bug。`git pull` 后对每个被改动
  的英文文件，检查同名 zh 译文是否受影响（公式改动 → 大概率受影响；
  文字润色 → 复读对应段落）。
- 复核结果在本文末尾「同步日志」登记。

## 单元对照约定

译文文件与原文文件**同名、同目录结构、同段落划分**。不要合并或
拆分段落（LaTeX 源层面的空行分段保持一致），方便逐行 diff 校对。
